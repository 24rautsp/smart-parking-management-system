🚗 Park a Vehicle

Auto-Assign O(N)

Assigns the first available slot via Linear Search. If full, enqueues to FIFO line.

🏁 Exit Vehicle & Calculate Fee

Hash Map O(1)

Frees the slot, computes fee, adds to History, and hands slot to next waiting car.

↩️ Undo Last Entry

Stack (LIFO)

Reverts the most recent vehicle entry using custom linked LIFO Action Stack.

💡 Uses ActionStack.pop() in O(1) time.

🏢 Visual Parking Lot Layout

Array of physical bays: Green = Available, Red = Occupied

⏳ Waiting Queue (Overflow Vehicles)

Custom FIFO Queue implemented using linked nodes (front/rear pointers). Front vehicle is automatically allotted the next vacated slot.
